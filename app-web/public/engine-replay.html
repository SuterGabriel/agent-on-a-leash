We turned it into rules

    Rules are sent to Viseca as the card's mandate. The engine checks every payment against them, plus protections that are always on: duplicates, lookalike shop names, shop text that gives orders, and sessions that don't look like you.

    Reproduce it yourself

    The same numbers come out of the repository in seconds, offline:

    npm run replay -- --all   # 45 purchases vs Viseca's answers
npm test                  # 291 automated tests
npm run live-review       # the learning comparison

    No AI model decides a payment. AI (Apertus, the Swiss open model) only reads what the customer writes in their language and profiles new customers. A test checks that the engine never imports it.

    Decisions and timings above are the recorded output of our engine (npm run replay, 25 Sep 2026) on the public data pack Viseca gave every team; "Viseca" is the expected decision from its reference_decisions.csv, which the engine never reads. Live and learning figures come from our runs on Viseca's live server (24 Sep 2026); live purchases have no published answer key.
