# Agent on a Leash · Wireframes

Low-fidelity wireframes for a new **Leash** tab in the card app (next to Card, Cockpit and Analytics), plus a desktop judge view.

- **`index.html`**: open this first. It shows all frames on one page, grouped by flow.
- **`png/`**: one image per frame, numbered in reading order. Use these for slides, chat or email.
- **`html/`**: each frame as its own page. Links inside the frames follow the flow (for example Decline → History, Revoke → confirmation → Revoked).
- **`source/`**: the editable canvas files (`.dc.html` + `canvas.json`). They only render inside the design canvas.
